# Notebook 优先的课程约定

本项目以可运行代码恢复深度学习基础并理解搜索、推荐与广告系统。Notebook 是学习入口，PPT 用于回查；这个约定只适用于本项目。

- 每节从一个能运行的问题开始，给出输入、张量形状、可修改参数和实际结果。
- 使用“先预测 → 只改一个变量 → 运行 → 解释对照”的顺序。保留负结果。
- 把代码分成短格。首次从头执行一次，之后重跑当前实验和下游格，明确前置变量。
- 算法辅助函数要能查看源码；正式训练复用项目训练器，沙盒模型注明未进入服务。
- 数学关系用断言或小规模穷举核对，例如 FM 梯度、DPP 贪心与增量等价；这些不替代业务效果评估。
- 真实日志、真实训练快照、构造张量、模拟流量分别说明。缺少曝光/作者/视频字段时，不伪造真实业务数据。
- 简化机制、算法数值复现、真实数据实验、完整论文复现分别标明。覆盖讲义主题不代表已经复现原论文训练配方、数据规模或收益。
- 使用 CPU 小实验和已保存快照；不自动启动原流计算 lab、不覆盖旧模型或用户已编辑的 Notebook。
- 新章节必须验证格式、清洁内核顺序执行、保存输出，并检查实际渲染。用户已有 Notebook 不通过重建脚本覆盖。

入口：`00_Course_Map.ipynb`。前两本为真实数据/双塔基础；03~10 对应全部 45 个讲义主题的章节配套。部分专题目前是明确标注的机制练习，后续可以逐步替换为更完整的真实数据训练实验。
