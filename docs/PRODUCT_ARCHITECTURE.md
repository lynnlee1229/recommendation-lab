# 模块归属先于页面与功能

一级只有四项：公用、搜索、广告、推荐。一级是知识领域与共享基础；模型、工具、数据和资源都要有父模块。不能因为有某个现成接口，就把它升到一级导航。

| 一级 | 二级入口 | 职责 |
|---|---|---|
| 公用 | 起步、基础学习路径（31–34）、实验方法、全局实验台账、公共源码 | 三领域共享的约定、记录与基础设施 |
| 搜索 | 学习路径、讲义与路线、检索实验、搜索实验记录、搜索源码 | 查询、文档、相关性、词法/向量/融合/重排 |
| 广告 | 学习路径、讲义与路线、点击预测、拍卖与预算、广告实验记录、广告源码 | 概率预测与决策分层；真实曝光和模拟市场分开 |
| 推荐 | 学习路径、数据与基线、召回与重排、特征与样本、双塔训练、推荐实验记录、讲义与论文、推荐源码 | 行为样本、候选排序、模型训练与竞赛实践 |

公用的全局台账可跨领域定位记录，不能跨领域比较指标。进入领域后，只能看到本领域实验记录与源码；确实共用的概率评估、实验registry和服务入口收在公用。网页复用相同API和模型，不复制服务或实验。

`web/navigation.js`集中声明模块、页面、课程阶段与旧链接映射；`web/app.js`负责同一视图的模块作用域与路由。URL使用`#模块/页面`，刷新、前进、后退和旧hash都解析到相同父模块。一级与模块内导航使用不同的landmark和当前位置标记。
