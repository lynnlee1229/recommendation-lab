# 广告课程补齐：学习和复现约定

本轮以A01–A18语义单元为验收对象，不以原Criteo实验字段定义课程范围。先修公用31–34；A01产品与参与方→A02计费→A03合约→A04搜索广告→A05多广告位拍卖→A06RTB→A07定向→A08候选→A09真实CTR→A10FM→A11转化→A12校准→A13出价→A14反馈→A15归因增量→A16底价→A17实验反作弊→A18账本。原18–24全部保留，19–20支持A09、22支持A12，18/23/24作为旧综合与模拟参考。

每个新Notebook含问题、先修、公式/算法与输入输出约定、先预测、单变量对照、运行断言、输出解释、局限、源码和练习。源码`reclab/ads_curriculum.py`提供可检查机制，网页广告模块提供讲义与路线；服务仍为原18580，Jupyter仍为原18581。

## 证据分层

- A09/A12引用原固定真实CTR训练与校准证据。A10使用同一官方Criteo固定分片前10,000条，train/select按原特征哈希组切分；词表只看train；26类别字段top64+unknown、8 epochs、batch256、Adam .02、seed42。线性模型与FM仅增加交互结构，FM复用推荐`learning.networks.fm_interaction`，额外参数单独报告。两个模型训练批次顺序一致；数字字段都不用，避免处理差异。select是开发诊断，不触碰audit、不做线上推断、不替换正式模型。
- 其他新增单元是明确构造机制或模拟。转化标签、延迟、上下文、随机分配、报价和点击都不是从Criteo伪造出来的真实日志。没有真实画像、转化、propensity或竞价历史，因此没有真实CVR/IPS/OPE或因果增收结果。
- A03穷举最优是小规模离线上界，不是在线最优保证；A05可分离CTR/相同广告质量、准线性效用、无预算；A06仅状态与反馈机制，不实现OpenRTB；A14积分式比例误差反馈不是完整PID；A16固定报价分布不包含长期战略响应；A18单进程账本不实现并发事务、退款和生产交付。

## 可复现与记录

显式训练：`PYTHONPATH=. .venv/bin/python scripts/run_ads_ctr_workshop.py`。每次通过同一ads registry新建workshop run，保存权重、词表、select预测与标签；这些留在被忽略的artifacts，Git只保留精简聚合指标。第一次精简结果为`results/2026-10-30-ads-curriculum/fm.json`，之后使用run-id命名，不覆写冻结教材结果。失败run保留。

重新执行Notebook可用`scripts/execute_notebooks.py --only <新章stem...>`；它创建干净项目内核并保存输出/HTML，不停止用户Jupyter或内核。新增章节清单与A单元运行记录见`ADS_CURRICULUM_COMPLETION.json`。
