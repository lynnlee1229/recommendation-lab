# 搜索学习路线与现有覆盖审计

核对日期：2026-10-30。基线：本地9bfd436（公用基础已提交，尚未推送）。本轮是课程设计与缺口盘点，不代表新增课程已实现。

按王树森课程的六条主线：基础 → 相关性 → 查询处理 → 召回 → 排序 → 查询推荐。下面将它们拆为可验收的教学单元；服务与课程组织是Lab教学展开，并非作者逐字目录。先修为公用31–34。

## 来源与采用范围

## 状态口径

“已覆盖”只表示现有材料已执行并覆盖该行的有限教学目标；“部分”表示有相关证据但缺教学内容；“机制”表示有简化替身，不能当作一般算法或真实业务复现；“缺失”表示未发现该目标的配套课程。不存在按文件数量估算的“完成率”。

## 补课实施规则

1. 先按上表语义单元安排先修和学习顺序，再决定Notebook数量与编号。旧综合章是实验参考，不是限定课程范围的模板。不得把多个缺口塞进几格通用演示后称完整。
2. 核心为全部上表目标；实现形式可以是真实小数据实验或明确的构造机制实验，但每行都要有概念、公式或算法、输入输出契约、单变量运行、结果解释与练习。生产规模训练、工业部署与最新前沿模型不是本轮“完整”的含义。
3. 已覆盖的旧章保留原文件与输出，仅在新课程地图里引用；不得重建/覆盖用户旧Notebook，不为美化课程改原正式模型、测试协议或效果。
4. 新训练先设计独立train/select边界，使用同一registry的新教学run；正式latest不得指向教学run。已查看测试集只能称诊断。新增数据先核实许可、固定版本、SHA与磁盘预算；无数据时把证据边界写在页面上。
5. 使用同一reclab服务、共享评估/索引/下载器和公用基础课；新增领域适配器应服务任务，不能另起Lab。补来源和“讲义与路线”入口，但不提升到一级导航。
6. 新章从当前未占用编号开始分配，先检查公用35本以及前序session新增编号；搜索先写，广告后写，不预占互相冲突的编号。
7. 新章清洁内核执行、保存输出并检查实际渲染；有数学不变量就断言，有真实训练就核验保存指标；浏览器检查路线、来源、交互、失败和窄屏，保留原API与课程回归。
8. 为每个单元写验收矩阵：交付文件/代码格/运行记录/证据类型/限制。未完成项只能标未完成，不能只靠文案从缺失改为已覆盖。

## 本轮结论

现有七本搜索Notebook是可复用的检索与重排实验，不是搜索全课程。优先补查询理解、缓存召回、相关性模型训练、排序目标与查询推荐，再把满意度和服务链路串起来。
